# Icon Assets

Place your icon images here. The chatbot needs the following 8 icons:

## Required Icons:

1. **security.png** - Security Services (🛡️ shield/lock icon)
2. **facility.png** - Facility Management (🏢 building icon)
3. **manpower.png** - Manpower/Payroll (👥 people/team icon)
4. **training.png** - Training (📚 book/education icon)
5. **careers.png** - Careers (💼 briefcase icon)
6. **about.png** - About Company (ℹ️ info icon)
7. **contact.png** - Contact & Locations (📞 phone icon)
8. **support.png** - Existing Client Support (🆘 help/support icon)

## Recommended Specifications:
- Format: PNG or SVG (SVG preferred for scalability)
- Size: 48x48px minimum (will be displayed at 48x48px)
- Background: Transparent
- Style: Simple, clean icons that work well in white color (will be inverted to white on blue background)
- Color: Any color (will be filtered to white in the UI)

## Where to get icons:
- **Free**: heroicons.com, lucide.dev, iconoir.com, tabler-icons.io
- **Premium**: iconscout.com, flaticon.com

## After adding icons:
The configuration files (conversationFlow.js and translations.js) will be automatically updated to use these images.
